# Восточные шахматы: Чанги, Сянци и Сёги

Настольное приложение для игры в Чанги (장기), Сянци (象棋, китайские шахматы) и Сёги (将棋, японские шахматы)
на русском языке. Игра выбирается переключателем в заголовке или в окне «Новая партия». Работает на Windows, Linux и Android; установщики для всех трёх лежат в [Releases](https://github.com/poplar3/eastern-chess/releases).

## Возможности

- Полные правила Чанги, сверенные с движком Fairy-Stockfish: дворец и его диагонали, пушка с «лафетом»,
  пропуск хода, шах и мат, **биджанг** (빅장), подсчёт очков с компенсацией Хана 1,5 очка (덤),
  повторения позиции и вечный шах, 100 полуходов без взятий.
- Выбор расстановки коней и слонов (상차림) для каждой стороны.
- Два вида фигур: европейские иконки или традиционные иероглифы.
- Счёт очков во время игры и подсказка, кто победит, если биджанг не разорвут.
- Игра против компьютера: 10 уровней от 18 급 до полной силы движка, или вдвоём за одним компьютером.
- ИИ-помощник: подсказка с тремя лучшими ходами, оценкой и ожидаемым ответом соперника, словесное описание
  плана, непрерывный анализ позиции.
- Оценка каждого хода во время игры (лучший / хороший / неточность / ошибка / зевок) с лучшей альтернативой.
- Разбор партии: график шансов, точность каждой стороны, список ошибок, лучшие продолжения; просмотр любого
  хода партии (клик по ходу или стрелки ← →).
- Краткие правила по кнопке «Правила».
- Задачи: маты в 1–4 хода и выигрыш материала, а также задачи по канону 박보 (каждый ход — шах, маты в 3–6 ходов), по пяти уровням (от 18 급 до 단). У каждой задачи описание,
  тактический приём с объяснением, подсказки по шагам и разбор решения; после решения позицию можно доиграть
  свободно или против компьютера. Прогресс сохраняется.
- 42 настоящие корейские задачи 박보 из DOS-игры «박보장기 1.0» с указанием источника: позиции и решения
  взяты из прохождения в блоге enky1 ([1–25](https://enky1.blogspot.com/2015/09/10-1.html),
  [26–50](https://enky1.blogspot.com/2015/09/10-2-2650.html)). Их можно отобрать фильтром «Корейские задачи».

- Курс обучения: 38 уроков по пяти уровням — от ходов фигур, мата и биджанга через защиту от шаха и пушки,
  связку, блокировку коня (멱), повторение и вечный шах до дебютных угроз, разменов, темпа, трудной защиты,
  пропуска хода и матов в четыре хода. В каждом уроке короткая теория с диаграммами и задания с проверкой:
  отметить ходы фигуры, найти ход, ответить на вопрос, решить задачи по теме, найти лучший ход в позиции из
  партии (ход оценивает движок).

- **Сянци и Сёги** с тем же набором возможностей: игра с компьютером (10 уровней) и вдвоём, подсказки и анализ,
  оценка ходов, разбор партии, правила, европейские иконки и иероглифы, задачи и курс обучения.
  - Сянци: река, дворец, «летающий генерал», пат — поражение, вечный шах проигрывает, троекратное повторение и
    50 ходов без взятий — ничья. Правило вечного преследования (AXF) не проверяется: такое повторение — ничья.
  - Сёги: сброс взятых фигур из руки, превращение (с выбором в окне), нифу, мат сбросом пешки (утифудзумэ)
    проигрывает поставившему его, четырёхкратное повторение (сэннититэ) — ничья, вечный шах проигрывает.
  - Задачи генерируются движком так же, как для Чанги: маты в 1–5 ходов (в том числе цумэ, где каждый ход — шах)
    и выигрыш материала: 190 задач Сянци и 233 задачи Сёги. Курсы обучения: 18 уроков Сянци и 15 уроков Сёги.
  - Движок играет с нейросетью (NNUE) в каждой игре: у Чанги, Сянци, Сёги, Макрука и Шатранджа своя сеть
    (см. «Нейросети»).
- **Макрук** (тайские шахматы) и **Шатрандж** (старинные персидские шахматы) на доске 8×8: игра с компьютером
  и вдвоём, подсказки, анализ, оценка ходов, разбор партии, правила, задачи и курс обучения
  (17 уроков макрука и 14 уроков шатранджа).
  - Задачи (маты в 1–2 хода, маты в 3 хода шахами и выигрыш материала) составлены без движка:
    `scripts/gen-chess8-puzzles.mjs` перебирает случайные позиции с небольшим числом фигур и полным перебором
    по правилам приложения находит решения, проверяя их на единственность.
  - Макрук: кхон и мет, пешки на третьей горизонтали превращаются в мета на шестой, пат — ничья, правило счёта
    (64 хода без пешек, 8–64 хода против одинокого короля; упрощённо, как в Fairy-Stockfish).
  - Шатрандж: ферзь — шаг по диагонали, слон прыгает через клетку по диагонали, пат и оголённый король — поражение,
    троекратное повторение и 50 ходов без взятий и ходов пешек — ничья.
  - Генерация ходов сверяется с Fairy-Stockfish в CI после сборки движка.

В планах: задачи из других корейских сборников.

## Задачи

Собственные задачи приложения генерируются движком и проверяются на единственность решения:

```bash
FAIRY_STOCKFISH=<путь> node scripts/gen-puzzles.mjs 200 raw-games.json                # из партий движка
FAIRY_STOCKFISH=<путь> MODE=compose node scripts/gen-puzzles.mjs 12000 raw-compose.json # этюды с малым числом фигур
node scripts/select-puzzles.mjs raw-games.json raw-compose.json                        # отбор в src/puzzles/own.json
FAIRY_STOCKFISH=<путь> MODE=bakbo node scripts/gen-puzzles.mjs 20000 raw-bakbo.json     # 박보: каждый ход — шах
BAKBO=1 node scripts/select-puzzles.mjs raw-bakbo.json                                 # отбор в src/puzzles/bakbo.json
```

Для Сянци и Сёги — те же скрипты с переменной `VARIANT`; `MODE=checks` составляет маты, где каждый ход — шах:

```bash
FAIRY_STOCKFISH=<путь> VARIANT=shogi MODE=checks node scripts/gen-puzzles.mjs 30000 sh-checks.json
FAIRY_STOCKFISH=<путь> VARIANT=shogi MODE=compose node scripts/gen-puzzles.mjs 10000 sh-compose.json
FAIRY_STOCKFISH=<путь> VARIANT=shogi node scripts/gen-puzzles.mjs 40 sh-games.json
VARIANT=shogi node scripts/select-puzzles.mjs sh-checks.json sh-compose.json sh-games.json  # в src/puzzles/shogi.json
```

Задачи из «박보장기 1.0» переписаны с картинок прохождения в `scripts/data/bakbo-classic.json` и проверяются
движком: в задачу попадает только позиция, где мат форсируется ровно за указанное в игре число ходов при
лучшей защите. Из 50 так подтверждаются 42 (в остальных соперник в DOS-игре отвечал заранее заданными ходами,
а при лучшей защите мата нет или он дольше). Равноценные другие решения сохраняются и засчитываются.

```bash
FAIRY_STOCKFISH=<путь> node scripts/import-bakbo-classic.mjs   # проверка и запись в src/puzzles/classic.json
```

Позиции для продвинутых уроков подбираются движком, а каждое задание курса проверяется:

```bash
FAIRY_STOCKFISH=<путь> MODE=games node scripts/gen-lesson-tasks.mjs 30 candidates.json    # лучший ход в партиях
FAIRY_STOCKFISH=<путь> MODE=defense node scripts/gen-lesson-tasks.mjs raw.json defense.json # единственная защита
FAIRY_STOCKFISH=<путь> node scripts/verify-lessons.mjs                                     # проверка всех уроков
```

Генерация ходов Сянци и Сёги сверяется с движком на тысячах позиций (`scripts/gen-movegen-fixtures.mjs`,
четвёртый аргумент — вариант). `npm test` проверяет, что каждое решение законно и действительно заканчивается матом или выигрышем материала.

## Сборка

Нужны Node.js 22 и Rust (stable).

```bash
npm ci
npm run fetch-engine   # Fairy-Stockfish и нейросети всех игр (Windows — скачивает, Linux — собирает)
npm test               # проверка правил
npx tauri build        # установщик в src-tauri/target/release/bundle
```

Для Linux готовых сборок с нейросетью Чанги нет: `fetch-engine` скачивает исходники Fairy-Stockfish и сеть Чанги
и собирает движок со встроенной сетью (нужны make, g++ и tar; `--rebuild` — пересобрать).
Готовый движок можно указать так: `FAIRY_STOCKFISH=<путь> npm run fetch-engine`. Собранный в CI движок для Linux
лежит в артефакте `fairy-stockfish-linux`.

Проверить, что изменение настроек движка его усиливает, можно матчем:
`FAIRY_STOCKFISH=<путь> node scripts/engine-match.mjs '{"Threads":3}' '{}' 10 300 1`.

### Нейросети

Свою сеть мы не обучаем: на это уходят недели работы видеокарт и миллиарды позиций из партий движка. Вместо этого
приложение использует лучшие готовые сети из [списка Fairy-Stockfish](https://fairy-stockfish.github.io/nnue/),
по одной на игру. Список сетей — в `scripts/nnue-nets.mjs`; чтобы добавить игру, достаточно вписать туда её сеть.

| Игра | Сеть | Размер | Матч «с сетью против без сети», 40 партий по 0,1 с на ход |
|---|---|---|---|
| Чанги | janggi-9991472750de (встроена в движок) | 11 МБ | — |
| Сянци | xiangqi-c07e94a5c7cb (авторы Pikafish) | 11 МБ | +40 −0 =0 |
| Сёги | shogi-9ab5e57f31d0 | 160 МБ | +40 −0 =0 |
| Макрук | makruk-a8c621e24a8c (подходит и камбоджийскому макруку) | 48 МБ | +34 −0 =6 (≈ +436 Elo) |
| Шатрандж | shatranj-09bfa52e776f | 48 МБ | +38 −0 =2 (≈ +636 Elo) |

`fetch-engine` скачивает сети (с GitHub или Google Drive), проверяет их по хешу из имени и кладёт рядом
с движком: на ПК — в `src-tauri/engine/nnue/`, на Android — в `jniLibs` под именами `libnnue_<сеть>.so`.
Скачанное хранится в `.nnue-cache/`. Приложение передаёт движку список сетей опцией `EvalFile`, а движок
сам берёт сеть, имя которой начинается с названия варианта. `node scripts/engine-smoke.mjs <движок>` проверяет,
что в каждой игре движок играет с сетью.

Матч сети против классической оценки (или двух любых настроек) для любой игры:

```bash
npm i --no-save ffish
VARIANT=shogi node scripts/nnue-match.mjs '{"EvalFile":"<путь>/shogi-9ab5e57f31d0.nnue"}' '{"Use NNUE":false}' 20 100 4
```

Интерфейс можно разрабатывать в браузере: `npm run engine-bridge` (мост к движку) и `npm run dev`.

Готовые установщики собираются в GitHub Actions (вкладка Actions → «Сборка» → артефакты `eastern-chess-windows`,
`eastern-chess-linux` с AppImage и deb, `eastern-chess-android` с APK). При публикации тега `v*` все они прикладываются
к одному релизу. Для сборки под Linux нужны пакеты `libwebkit2gtk-4.1-dev`, `libappindicator3-dev`,
`librsvg2-dev` и `patchelf`.

### Android

APK для телефонов с 64-битным ARM (arm64-v8a — почти все телефоны последних лет, Android 7 и новее) собирается
там же: артефакт `eastern-chess-android`, файл `eastern-chess-android-arm64.apk`. Его можно скопировать на телефон и установить,
разрешив установку из неизвестных источников.

Движок собирается из исходников компилятором Android NDK с той же встроенной нейросетью Чанги и кладётся в APK
как `libfairystockfish.so`: Android разрешает запускать программы только из папки нативных библиотек приложения.
Сети остальных игр лежат там же как `libnnue_<сеть>.so`; при запуске приложение делает на них ссылки с настоящими
именами в своей папке кеша.
Проект Android лежит в `src-tauri/gen/android`. Локальная сборка (нужны Android SDK, NDK и JDK 17+):

```bash
rustup target add aarch64-linux-android
export ANDROID_HOME=<путь к SDK> NDK_HOME=<путь к NDK> ANDROID_NDK_HOME=<путь к NDK>
npm run fetch-engine -- --android
npx tauri android build --apk --target aarch64
```

Без ключа подписи APK подписывается отладочным ключом, который на сборщике каждый раз новый, — тогда новую версию
поверх старой не поставить, сначала нужно удалить приложение (вместе с прогрессом задач). Чтобы обновления
ставились поверх, создайте ключ один раз:

```bash
keytool -genkeypair -v -keystore janggi.jks -alias janggi -keyalg RSA -keysize 2048 -validity 10000
base64 -w0 janggi.jks   # содержимое — в секрет ANDROID_KEYSTORE_BASE64
```

и добавьте в Settings → Secrets and variables → Actions секреты `ANDROID_KEYSTORE_BASE64`,
`ANDROID_KEYSTORE_PASSWORD`, `ANDROID_KEY_ALIAS` (`janggi`) и `ANDROID_KEY_PASSWORD`. Сам файл ключа храните
у себя: без него обновить приложение не получится.
